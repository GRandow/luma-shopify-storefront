# Luma Storefront

![React](https://img.shields.io/badge/React-19-61DAFB?logo=react)
![TypeScript](https://img.shields.io/badge/TypeScript-3178C6?logo=typescript)
![Vite](https://img.shields.io/badge/Vite-646CFF?logo=vite)
![TailwindCSS](https://img.shields.io/badge/TailwindCSS-06B6D4?logo=tailwindcss)

A modern e-commerce storefront built with React, TypeScript, and Vite. It simulates a complete online shopping experience, including authentication, product browsing, cart management, wishlist, and checkout.

🚀 **Live Demo:** https://grandow.github.io/luma-storefront/

## Features

- Product search, filtering, sorting, and pagination
- Product details with image gallery and recommendations
- Persistent shopping cart and wishlist
- User authentication (DummyJSON)
- Multi-step checkout
- Responsive design
- Dark mode

## Tech Stack

- React 19
- TypeScript
- Vite
- React Router
- TanStack Query
- Zustand
- Tailwind CSS
- React Hook Form
- Zod
- Vitest

## Getting Started

```bash
npm install
npm run dev
```

To create a production build:

```bash
npm run build
```
